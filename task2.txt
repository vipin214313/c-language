Haan, is note ka simple meaning ye hai:

> **Aaj ka task:** C programming mein jo multiple programs seekhe hain, unmein se **minimum 25 programs ko functions ka use karke convert karna hai**, aur functions ka **return type `void`** hona chahiye.

### Tumhe kya karna hai?

Har program ko is structure mein banana hai:

```c
#include <stdio.h>

void programName()
{
    // input
    // logic
    // output
}

int main()
{
    programName();

    return 0;
}
```

### `void` ka kya matlab hai?

`void` ka matlab hai ki function **koi value return nahi karega**.

Example:

```c
void addition()
{
    int a, b;

    printf("Enter two numbers: ");
    scanf("%d %d", &a, &b);

    printf("Sum = %d", a + b);
}
```

Yahan `addition()` calculation karke **directly output print** kar raha hai. Ye `main()` ko koi value return nahi kar raha.

## 14. Profit or Loss

**Logic:**

* `SP > CP` → Profit
* `CP > SP` → Loss
* `CP = SP` → No profit, no loss

```c
#include <stdio.h>

void profitLoss()
{
    float cp, sp;

    printf("Enter Cost Price: ");
    scanf("%f", &cp);

    printf("Enter Selling Price: ");
    scanf("%f", &sp);

    if (sp > cp)
    {
        printf("Profit = %.2f", sp - cp);
    }
    else if (cp > sp)
    {
        printf("Loss = %.2f", cp - sp);
    }
    else
    {
        printf("No Profit No Loss");
    }
}

int main()
{
    profitLoss();
    return 0;
}
```

## 15. Total and Percentage of 5 Subjects

**Logic:**

`Total = s1 + s2 + s3 + s4 + s5`

Agar har subject 100 marks ka hai:

`Percentage = (Total / 500) × 100`

```c
#include <stdio.h>

void marks()
{
    float s1, s2, s3, s4, s5;
    float total, percentage;

    printf("Enter marks of 5 subjects: ");
    scanf("%f %f %f %f %f", &s1, &s2, &s3, &s4, &s5);

    total = s1 + s2 + s3 + s4 + s5;

    percentage = (total / 500) * 100;

    printf("Total = %.2f\n", total);
    printf("Percentage = %.2f%%", percentage);
}

int main()
{
    marks();
    return 0;
}
```

## 21. Swap Two Numbers

**Logic:** Temporary variable use karenge.

```text
temp = a
a = b
b = temp
```

```c
#include <stdio.h>

void swap()
{
    int a, b, temp;

    printf("Enter two numbers: ");
    scanf("%d %d", &a, &b);

    temp = a;
    a = b;
    b = temp;

    printf("After swapping:\n");
    printf("a = %d\n", a);
    printf("b = %d", b);
}

int main()
{
    swap();
    return 0;
}
```

## 25. Electricity Bill

Ek simple slab example:

* First 100 units → ₹5/unit
* Next 100 units → ₹7/unit
* Above 200 units → ₹10/unit

```c
#include <stdio.h>

void electricityBill()
{
    int units;
    float bill;

    printf("Enter electricity units: ");
    scanf("%d", &units);

    if (units <= 100)
    {
        bill = units * 5;
    }
    else if (units <= 200)
    {
        bill = (100 * 5) + ((units - 100) * 7);
    }
    else
    {
        bill = (100 * 5) + (100 * 7) + ((units - 200) * 10);
    }

    printf("Electricity Bill = %.2f", bill);
}

int main()
{
    electricityBill();
    return 0;
}
```

## 🔥 Sabse important concept

Tumhare **25 programs ka main objective calculation nahi, `void function` samajhna hai.**

Har program mein ye pattern dekho:

```c
void addition()
{
    // input
    // logic
    // output
}
```

Aur:

```c
int main()
{
    addition();
    return 0;
}
```

### Yaad rakhne ka formula:

**`void` = No return value**

```text
main()
  ↓
function call
  ↓
void function()
  ↓
Input
  ↓
Logic
  ↓
Output
```

Isliye tumhare assignment mein **25 अलग-अलग programs hain, lekin function ka concept almost same rahega**.
